# Knowledge expansion and glossary — November 5, 2026

## Outcome and limits

50 distinct source URLs now map to 50 captured Markdown summaries (previously 15). These are focused paraphrases of selected official educational content, not complete downloaded articles. The source-count checkpoint meets the minimum 50 target; comprehensiveness and answer quality still require broader evaluation. The 26 glossary definitions are separate data and do not increase the article count.

## Exact code and data changes

- `articles/sources.json`: appended 35 records; retained all 15 existing records. Each new record has title, original URL, publisher, detailed topic, checked_on date, and local filename. Review date means the capture was reviewed, not the original publication date. The FDIC page's search-indexed official text was available, but direct page fetching returned HTTP 403 during verification.
- The 35 new Markdown files below contain the title, publisher/link, review date, capture-scope label, and selected educational summary. No current rates or tax-year thresholds were added.
- `articles/glossary.json`: added 26 objects with term, definition, topic, source_url, and source_title. Each source_url points to an article in the catalog. The glossary is intentionally used for browsing and is not passed to the article embedding pipeline.
- `src/finnie/knowledge.py`: added load_glossary(), which parses local JSON; added search_glossary(query, category), which trims and case-folds text, combines category matching with a substring search over term/definition/topic, and returns alphabetically sorted entries. Both run locally without network calls.
- `src/finnie/ui.py`: imported the glossary helpers; added an Articles/Glossary radio in Knowledge; retained article browsing and filtering; added glossary category and search controls, matching counts, empty-result feedback, expandable definitions, and source links. Dollar signs are escaped for Markdown rendering. Incremented workflow_version from 10 to 11 so an existing Streamlit session recreates its workflow and does not keep the previous in-memory 15-source index. Existing visible history is preserved.
- `tests/test_knowledge.py`: strengthened catalog checks to require at least 50 sources and unique filenames as well as URLs. Added glossary integrity/source-link checks and combined text/category search checks, including whitespace/case normalization, definition matching, empty results, and alphabetical order.
- `README.md` and `.agent/PLAN.md`: updated the active milestone, counts, verification, limitations, acceptance steps, and remaining work. Earlier development-history notes may describe earlier corpus states.
- Ignored `.finnie/knowledge_index.json`: regenerated by the existing RAG loader, containing 59 chunks and the native FAISS index. No RAG, chunking, embedding, routing, or dependency code changes were needed in this milestone.

## Why new content reaches answers

sources.json -> read each mapped Markdown file -> chunk_document() -> embed_texts() -> FAISS index -> question embedding -> nearest passages -> grounded answer and citations.

The loader fingerprints the catalog metadata, source text, and configured embedding model. Adding source files changes that fingerprint. The next load rebuilds and saves the index; later loads with the same fingerprint reuse it. A running workflow also holds an in-memory index, so its version was incremented to refresh it when Streamlit reruns the edited script. Glossary searches take a separate local JSON path and incur no embedding or model usage.

## Learner acceptance

Restart Streamlit using `python -m streamlit run src/finnie/ui.py` from the project directory. Open Knowledge, choose Glossary, and search APR or compound. In Articles, select Saving and inspect CDs or deposit insurance. In Finance Q&A use All topics and ask:

1. How do TIPS adjust for inflation?
2. What is a credit card grace period?
3. Can a broker sell investments in a margin account?

Check that answers discuss the requested concept and link to the corresponding Treasury, CFPB, or SEC source. The prepared saved index should be reused unless source content or the embedding model changes again.
