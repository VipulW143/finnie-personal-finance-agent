# Finnie Capstone

## Goal
Build the AI Finance Assistant in the adjacent project requirements and learn the system by implementing it in small, understandable steps.

## Working rules
- Work only on the current milestone and the files it needs; do not load the whole course folder.
- Before a new concept, explain it briefly in beginner-friendly terms and connect it to the course.
- For learning exercises, give a hint and let the learner try before showing a complete solution. If asked to implement directly, make the smallest useful change and explain it.
- Keep code simple, modular, and runnable locally in VS Code. Use Colab only for isolated experiments that benefit from notebooks.
- Keep secrets in an untracked `.env`; never print or commit secret values.
- Treat outputs as financial education, cite retrieved sources, and avoid personalized buy/sell/tax advice.
- Do not add dependencies or expand scope without a clear need. Read only relevant project documents and source files.

## Project checkpoints
Track the active milestone and decisions in `README.md`; track sequence and acceptance criteria in `.agent/PLAN.md`.
