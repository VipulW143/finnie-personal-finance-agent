# Executing an Order

Source: [U.S. Securities and Exchange Commission (SEC) Investor.gov](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/executing-order)
Reviewed November 5, 2026.
Capture: selected educational summary; not the full source article.

Placing a trade order and executing it are different events. A brokerage may route an order to an exchange or another trading venue, or execute it using its own inventory through internalization. Routing choices can affect price and execution speed.

A broker has a duty of best execution when handling customer orders. An opportunity for price improvement can sometimes produce a better price, but it is not guaranteed. Market prices may change while an order is being routed, so an execution can differ from a previously displayed quote. Understanding order routing helps explain why a quote is not a guaranteed trade price.
